Before you start

Use an installed Chromium-family browser with graphics acceleration enabled. WebGPU is required for final rendering. If it is unavailable, WebGL 2 can still preview the scene. Browser and GPU support varies; the app probes capabilities when it starts.

The default window has no browser tabs or address bar. The browser is supplied by you, and is not bundled into the executable. Application assets need no external services or downloads.

The packaging targets are macOS, Windows and Linux, on amd64 and arm64. Native Windows/Linux release checks and broader GPU validation remain open. This is not a claim of tested graphics support on every target.

Build from source

Install Go 1.26 or newer and Git. Node 22+ is used only for development tests and website generation. There is no npm installation or frontend build step.

git clone https://github.com/robert-mcdermott/lithosky.git
cd lithosky
go build -trimpath -o bin/lithosky .
./bin/lithosky

On Windows, use go build -trimpath -o bin/lithosky.exe ., then run .\bin\lithosky.exe in PowerShell. Move the executable wherever you like; it does not need the source checkout to run.

Release archives

The repository includes a packaging command that builds six platform archives and a SHA256SUMS file. Each archive contains one executable, license notices, a launch guide and the three portable scene files. No published binary download is promised by this development site.

After a release is published, choose the archive matching your OS and architecture from the repository’s release page. Extract it before launching. On macOS, Apple silicon uses arm64; Intel uses amd64.

Verify before extracting

Compare the archive’s SHA-256 hash with its entry in the release’s SHA256SUMS file. Checksums detect mismatched downloads; they do not provide a publisher signature.

# macOS
shasum -a 256 lithosky-VERSION-darwin-arm64.tar.gz
# Linux
sha256sum lithosky-VERSION-linux-amd64.tar.gz
# Windows PowerShell
Get-FileHash .\lithosky-VERSION-windows-amd64.zip -Algorithm SHA256

These initial packages are unsigned and not notarized. Operating systems may require approval before opening a trusted download. Do not disable system-wide security settings to run it.

Launch & troubleshoot

./lithosky --version
./lithosky --browser '/path/to/browser/executable'
./lithosky --no-open
./lithosky --window=browser

--no-open prints a loopback address for manual use. --window=browser explicitly opens a regular browser tab. If the default app window cannot launch, the error explains these alternatives.

For GPU problems, open Graphics & compatibility in the studio, select Automatic and choose Retry graphics. WebGL 2 compatibility provides a preview; it does not enable the final tracer.

Recovery files live in your user configuration directory under Lithosky. You can choose another location with --data-dir /path/to/recovery. Keep named .lithosky downloads as portable backups.
